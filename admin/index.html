ڕێکخستنی قفڵ

ئەم هەنگاوە تەنها یەکجار دەکرێت. کلیلێکی GitHub دروست دەکەیت و ئێمە بە کۆدەکەت قفڵی دەکەین. دواتر بۆ زیادکردنی هەواڵ تەنها کۆدەکە پێویستە.

  1. بە هەژماری GitHubـی خاوەنی ماڵپەڕەکە ئەم لینکە بکەرەوە: دروستکردنی تۆکن ↗
  2. Token name: هەر ناوێک (بۆ نموونە puk-news). Expiration: ماوەیەکی درێژ هەڵبژێرە، بۆ نموونە ساڵێک.
  3. Repository access ← Only select repositories ← puksportsboard
  4. Permissions ← Contents ← Read and write
  5. Generate token، ئینجا کۆپی بکە و لێرە دایبنێ.
