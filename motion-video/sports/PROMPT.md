# فەرمانی ئامادە بۆ ڤیدیۆی وەرزشەکان

ئەم نووسینە کۆپی بکە، تەنها ناوی وەرزشەکە بگۆڕە (لە نێوان « »)، و لە
دانیشتنێکی نوێی Claude Code بۆ ئەم ڕیپۆیە پەیستی بکە. هەر جارێک ڤیدیۆیەکی
٤٥ چرکەیی، 2D و جوڵاو، بە ڕەنگەکانی بۆرد و بە میوزیکی تایبەتی خۆی دروست دەکات.
لیستی هەموو وەرزشەکان لە [SPORTS.md](SPORTS.md) دایە.

```text
ڤیدیۆیەکی ٤٥ چرکەیی بۆ وەرزشی «تۆپی پێ» دروست بکە، بە شێوازی ڤیدیۆکانی بۆردی وەرزشی.

١. ئەگەر فایلی motion-video/make_sport.sh لەم لقەدا نییە، سەرەتا ئەمە لێبدە:
   git fetch origin claude/motion-video-logo-player-p300dt && git merge --no-edit origin/claude/motion-video-logo-player-p300dt
٢. فایلی .claude/skills/sport-video/SKILL.md بخوێنەوە و هەنگاوەکانی وەک خۆی جێبەجێ بکە.
٣. ئەگەر دەقەکانی ئەم وەرزشە لە motion-video/sports/sports.json دا نین، بە کوردیی سۆرانیی ڕەوان و زانیاریی ڕاست بیاننووسە.
٤. پێش دروستکردن وێنەکانی پشکنین (stills) سەیر بکە کە هیچ نووسینێک تێکنەچووبێت.
٥. ڤیدیۆکە بە 4K و میوزیکەوە بۆم بنێرە، پاشان commit و push بکە. وەڵامم بە کوردی بدەوە.
```

## تێبینی

- ڕەنگەکان: سەوزی لۆگۆ (#129901)، بێج، شینی نەوتی، و کەمێک ڕەش.
- میوزیک: بەپێی جۆری وەرزشەکە (بەهێز، قارەمانانە، ئارام و جوان، یان سەرکێشی)
  و بە ئامێرە ڕاستەقینەکانی پیانۆ، کەمان، چێلۆ، هۆڕن و هارپ؛ دەنگی یارییەکەش
  (لێدانی تۆپ، فیکە، زەنگ، ئاو...) لەگەڵ جوڵەکاندا ڕێکە.
- ئەگەر وەرزشێک لە کوردستان نییە، ڤیدیۆکە دەڵێت «بەم زووانە لە کوردستان /
  لە داهاتوودا دێت».
- ئەگەر ئەم لقە (claude/motion-video-logo-player-p300dt) لەگەڵ main یەکبخەیت،
  هەنگاوی یەکەم پێویست نابێت.
