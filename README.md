# وێبسایتی بۆردی وەرزشیی یەکێتیی نیشتمانیی کوردستان

وێبسایتێکی داینامیک بۆ بڵاوکردنەوەی هەواڵ، وێنە و چالاکییەکانی بۆردی وەرزش.

- **خەڵکی ئاسایی** سایتەکە دەبینن: هەواڵەکان، وێنەکان، گەڕان، بەشەکان، دەربارە و پەیوەندی.
- **تەنها تۆ** بە **کۆدێکی نهێنی** دەچیتە ناو **کۆنترۆڵ پانێڵ** (`/admin`) و ڕۆژانە وێنە و نووسین دادەنێیت.

دیزاینەکە لەسەر کیتی جوڵە و فۆنت و ڕەنگی بۆردی وەرزش دروستکراوە (فۆنتی Zain، ڕەنگی نیۆنی سەوز، جوڵەی دێڕ بە دێڕ و وشە بە وشە) — بڕوانە [docs/motion-kit.md](docs/motion-kit.md).

---

## ١. کارپێکردن لەسەر کۆمپیوتەر

پێویستت بە [Node.js](https://nodejs.org) ـە (وەشانی ١٨ یان نوێتر). هیچ پاکێجێکی تر پێویست نییە.

```bash
ADMIN_CODE=کۆدەکەی-خۆت node server.js
```

پاشان بکەرەوە:

- سایتەکە: http://localhost:3000
- کۆنترۆڵ پانێڵ: http://localhost:3000/admin

ئەگەر `ADMIN_CODE` دانەنێیت، سێرڤەرەکە خۆی کۆدێک دروست دەکات و لە شاشەکەدا نیشانی دەدات
(هەروەها لە فایلی `data/FIRST-ADMIN-CODE.txt` دا دەینووسێت). دوای چوونەژوورەوە لە
«ڕێکخستنەکان»ەوە بیگۆڕە.

## ٢. کۆنترۆڵ پانێڵ

| بەش | چی دەکات |
|---|---|
| **＋ بابەتی نوێ** | ناونیشان، بەش، بەروار، چەند وێنەیەک (ڕاکێشان یان هەڵبژاردن)، نووسین. وێنەکان خۆکار بچووک دەکرێنەوە. |
| **بابەتەکان** | لیستی هەموو بابەتەکان — بینین، دەستکاری، سڕینەوە. |
| **ڕێکخستنەکان** | لۆگۆ، وێنەی سەرەوە (بانەر)، ناوی سایت، دروشم، دەربارە، بەشەکان، تەلەفۆن، ئیمەیڵ، سۆشیاڵ میدیا، گۆڕینی کۆد. |

تێبینییەکان:

- **ڕەشنووس:** ئەگەر «بڵاوکراوە» لابدەیت، بابەتەکە پاشەکەوت دەبێت بەڵام خەڵک نایبینن.
- **بابەتی سەرەکی:** بە گەورەیی لە سەرەوەی لاپەڕەی سەرەکی دەردەکەوێت.
- **نووسین:** دێڕی بەتاڵ = پەرەگرافی نوێ. `**وشە**` = تۆخ. بەستەرەکان خۆکار دەبنە لینک.
- دوای ٨ هەوڵی هەڵە، چوونەژوورەوە بۆ ١٥ خولەک دادەخرێت.

## ٣. داتاکان لە کوێن؟

هەموو شتێک لە بوخچەی `data/` (یان ئەو شوێنەی `DATA_DIR` دیاری دەکات):

```
data/posts.json      بابەتەکان
data/settings.json   ڕێکخستنەکان
data/auth.json       کۆدی نهێنی (شێوەی هاشکراو)
data/uploads/        وێنەکان
```

بۆ **باکئەپ** تەنها ئەم بوخچەیە کۆپی بکە. ئەم بوخچەیە ناچێتە ناو git.

## ٤. بڵاوکردنەوە لەسەر ئینتەرنێت

سایتەکە سێرڤەرێکی Node.js ـە، بۆیە پێویستی بە هۆستێکە کە Node کار پێبکات و
**دیسکی هەمیشەیی** هەبێت (بۆ ئەوەی وێنە و بابەتەکان نەسڕێنەوە).

**Render.com** (ئاسانترین):
1. ئەم ڕیپۆیە بە Render ببەستەوە → New → Blueprint. فایلی `render.yaml` هەموو شتێک ڕێکدەخات (دیسکی ٥GB).
2. لە Environment، `ADMIN_CODE` دابنێ.
3. ئەگەر دۆمەینی خۆت هەیە، `SITE_URL` دابنێ (بۆ نموونە `https://puksport.krd`) بۆ ئەوەی وێنەکان لە فەیسبووک/واتساپ دروست دەربکەون.

**Railway / Fly.io / VPS:** `Dockerfile` ئامادەیە. volumeـێک بە `/data` ببەستەوە.

```bash
docker build -t puk-sports .
docker run -d -p 80:3000 -v puk-data:/data -e ADMIN_CODE=کۆدەکەت puk-sports
```

> ⚠️ هۆستی بەخۆڕایی بێ دیسک (وەک Render Free) هەموو وێنە و بابەتەکان دەسڕێتەوە لەگەڵ هەر دەستپێکردنەوەیەک.

## ٥. گۆڕاوەکانی ژینگە

| گۆڕاو | بنەڕەت | مانا |
|---|---|---|
| `PORT` | `3000` | پۆرت |
| `DATA_DIR` | `./data` | شوێنی داتا و وێنەکان |
| `ADMIN_CODE` | — | کۆدی کۆنترۆڵ پانێڵ (هەمیشە کار دەکات) |
| `SITE_URL` | خۆکار | ناونیشانی تەواوی سایت |

## ٦. پێکهاتەی پڕۆژەکە

```
server.js            سێرڤەر: لاپەڕەکان، API، چوونەژوورەوە، وێنەکان
public/admin.html    کۆنترۆڵ پانێڵ
public/js/admin.js   کۆدی کۆنترۆڵ پانێڵ
public/js/site.js    پێشاندانی وێنە بە گەورەیی و هاوبەشکردن
public/js/motion.js  جوڵەکان (لە کیتەکەوە)
public/css/          tokens / components / motion (کیت) + site.css + admin.css
public/fonts/        فۆنتی Zain
```

هەروەها `/feed.xml` (RSS) و `robots.txt` (کۆنترۆڵ پانێڵ لە گووگڵ دەشارێتەوە) هەن.
