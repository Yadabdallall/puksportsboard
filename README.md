# ئەندازیارنامە — ئینسایکلۆپیدیای بەشە ئەندازیارییەکان

ئەم ماڵپەڕە ئینسایکلۆپیدیایەکی سادە و جێگیرە؛ تیشک دەخاتە سەر گرنگترین بەشەکانی ئەندازیاری، سروشتی کارکردنیان، نەرمەکاڵا سەرەکییەکان، و بوارەکانی کار لە هەریەکەیاندا. ئامانجمان هاوکاریکردنی تۆیە لە تێگەیشتن و هەڵبژاردنی دروستی بەشەکەت.

## چی تێدایە؟

- **١٤ بەشی ئەندازیاری**: شارستانی، تەلارسازی، میکانیک، کارەبا، کۆمپیوتەر، نەرمەکاڵا، گەیاندن، کیمیا، نەوت، سەرچاوەکانی ئاو، پزیشکی، ئاسمانی و فڕین، پیشەسازی، ڕووپێوی و جیۆماتیکس — لەگەڵ کورتەی ١٠ بەشی تر.
- بۆ هەر بەشێک: بەشەکە چۆنە، سروشتی کارکردن، وانەکانی هەر قۆناغێک، ژمارە و ناوی لقەکان، پسپۆڕییەکانی ماستەر و بوارەکانی دکتۆرا، نەرمەکاڵا سەرەکییەکان، بوارەکانی کار، و «ئایا دەزانی؟».
- **ڕەنگی کڵاوی هەر بەش**: هەموو پەڕەی بەشەکە بە ڕەنگی کڵاوەکەی دەگۆڕێت، و کاتێک دەچیتە ژوورەوە کڵاوەکە بە ئەنیمەیشن لەسەرت دادەنرێت.
- **سەلامەتی**: کۆدی ڕەنگی کڵاو لە سایت، جۆرەکانی کڵاو (Type I/II)، پۆلە کارەباییەکان (Class G/E/C)، شێوەکانی کڵاو، ستانداردەکان، و ٢١ جۆر کەرەستەی پاراستنی کەسی (PPE) — هەروەها کەرەستەی پێویستی هەر بەشێک بە جیا.
- **٧٠ ئەندازیاری زیرەک** (٥ کەس بۆ هەر بەش) و **٢١٠ پڕۆژەی جیهانی** (٣ پڕۆژە بۆ هەر کەسێک) لەگەڵ وێنە.
- تاقیکردنەوەیەکی ٦ پرسیاری بۆ دۆزینەوەی گونجاوترین بەش.
- باکگراوندی جووڵاوی بلووپرینت (چەرخی ددانەدار، تۆڕی خاڵ، هێڵی پێوان) کە لەگەڵ سکرۆڵ و ماوس دەجووڵێت، و نووسینەکان لەگەڵ سکرۆڵ دەردەکەون و دەجووڵێن.
- فۆنتی **Zain** (لە Google Fonts). ژمارە کوردییەکان (٠١٢٣…) لە Vazirmatn وەردەگیرێن، چونکە Zain ژمارەکان بە شێوەی لاتینی دەکێشێت.

## وێنەکان

وێنەی ئەندازیاران و پڕۆژەکان لە کاتی کردنەوەی ماڵپەڕەکەدا ڕاستەوخۆ لە API ی ویکیپیدیا وەردەگیرێن (وێنەی ئازادی ویکیمیدیا کۆمنز) و بۆ ١٤ ڕۆژ لە وێبگەڕدا هەڵدەگیرێن. ئەگەر وێنەیەک نەدۆزرایەوە، پیتی یەکەمی ناوەکە یان ئایکۆنی بەشەکە پیشان دەدرێت. لە هەر کارتێکدا بەستەری «وێنەکان لە گووگڵ» و «ویکیپیدیا» هەیە.

## چۆن بیکەیتەوە

ماڵپەڕەکە تەنها HTML/CSS/JavaScript ـە و پێویستی بە build نییە:

```bash
python3 -m http.server 8000
# پاشان بکەرەوە: http://localhost:8000
```

بۆ بڵاوکردنەوە لە GitHub Pages: **Settings → Pages → Deploy from a branch** و لقەکە و فۆڵدەری `/ (root)` هەڵبژێرە.

## پێکهاتەی فایلەکان

```
index.html            پەڕەی سەرەکی
assets/css/style.css  هەموو دیزاین و ئەنیمەیشنەکان
assets/js/common.js   ئایکۆن، کڵاو، PPE، ستاندارد، تاقیکردنەوە
assets/js/depts-*.js  داتای ١٤ بەشەکە و ئەندازیاران و پڕۆژەکان
assets/js/bg.js       باکگراوندی جووڵاو (canvas)
assets/js/app.js      ڕووکار، ڕێڕەو (#/dept/<id>)، وێنەکان و ئەنیمەیشن
```

بۆ زیادکردنی بەشێکی نوێ، ئۆبجێکتێکی نوێ بە هەمان شێوەی بەشەکانی تر بخەرە ناو یەکێک لە فایلەکانی `depts-*.js`.

> تێبینی: ڕەنگی کڵاوی بەشەکان لەم ماڵپەڕەدا بۆ ناساندن و جیاکردنەوەیە؛ لە سایتی ڕاستەقینەدا ڕێسای کۆمپانیا و وڵات پەیڕەو دەکرێت.
