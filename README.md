# ئەندازیارنامە — ئینسایکلۆپیدیای بەشە ئەندازیارییەکان

ئەم ماڵپەڕە ئینسایکلۆپیدیایەکی سادە و جێگیرە بۆ هەموو ئەوانەی ئەندازیارییان خۆش دەوێت: خوێندکار، ئەندازیار، مامۆستا و هەر کەسێکی کونجکۆڵ. بەشە ئەندازیارییەکان، بژمێری ڕۆژانەی کار، ستانداردە جیهانییەکان، گەورەترین پڕۆژەکان، باشترین زانکۆکان، شێوازەکانی تەلارسازی و مەزنترین ئەندازیارانی جیهان و کوردستان لە یەک شوێندا.

**4 زمان:** کوردی (سۆرانی) · العربية · English · Deutsch — هەموو ژمارەکان بە لاتینی (0-9) و تەنها فۆنتی **Zain** بەکاردێت (لە ناو ماڵپەڕەکە خۆی دانراوە، بۆ خێرایی).

دیزاینەکە سادە و minimal ـە: کڵاوەکان و مۆدێلە 3D ـەکان ناجووڵێن تا خۆت نەیانجووڵێنیت، نووسینەکان بە نەرمی دێڕ بە دێڕ و وشە بە وشە دەردەکەون (کیتی جوڵەی تێکست)، و باکگراوندە جووڵاوەکەی هەر بەشێک وەک خۆی ماوە.

## چی تێدایە؟

- **14 بەشی ئەندازیاری**: شارستانی، تەلارسازی، میکانیک، کارەبا، کۆمپیوتەر، نەرمەکاڵا، گەیاندن، کیمیا، نەوت، سەرچاوەکانی ئاو، پزیشکی، ئاسمانی و فڕین، پیشەسازی، ڕووپێوی و جیۆماتیکس — لەگەڵ کورتەی 10 بەشی تر.
- بۆ هەر بەشێک: بەشەکە چۆنە، سروشتی کارکردن، وانەکانی هەر قۆناغێک، لقەکان، ماستەر و دکتۆرا، نەرمەکاڵا، بوارەکانی کار، سەلامەتی، «ئایا دەزانی؟» و بەستەر بۆ ستاندارد و بژمێرەکانی ئەو بەشە.
- **بژمێرە ئەندازیارییەکان** (`#/tools`): چیمەنتۆ و لم و چەوی کۆنکرێت، بلۆک و ملاط، کێشی شیش، شیشی بڕگەیەکی کۆنکرێت، قەبارەی کێبڵ (IEC 60364)، قەبارەی بریکەر، ڕووناکیی ژوور (Lux)، تەنی سپلیت (BTU)، قەبارەی دەکت و گۆڕینی یەکەکان.
- **ستانداردە جیهانییەکان** (`#/standards`): 26 ڕێکخراو (ACI، ASTM، ISO، IEC، IEEE، NFPA، ASME، ASHRAE، Eurocode، BSI، DIN، API، FIDIC، IQS …) لەگەڵ گرنگترین کۆدەکانیان و پاڵاوتن بەپێی بەش.
- **20 گەورەترین پڕۆژەی ئەندازیاری** (`#/projects`): مۆدێلی 3D (بە ڕاکێشان دەسووڕێت)، بلوپرنت لەگەڵ پێوانە، و وێنە.
- **20 باشترین زانکۆی ئەندازیاری** (`#/universities`): MIT، ستانفۆرد، کامبریج، ETH، هارڤارد، باوهاوس … و ئەو بەشانەی تێیدا باشترینن، لەگەڵ بورسیەکان.
- **شێوازەکانی تەلارسازی** (`#/styles`): 21 شێواز لە میسری کۆنەوە تا مینیمالیزم و پارامێتریک، و میراتی کوردستان.
- **ئەندازیارانی کورد**: پێنج زانای کورد لە لیستی باشترین 2%ی زانایانی جیهان (ستانفۆرد).
- **140 ئەندازیاری مەزن** (10 کەس بۆ هەر بەش) لەگەڵ ژیاننامە و 3 پڕۆژەی جیهانی بۆ هەر کەسێک.
- **110 نەرمەکاڵا** لەگەڵ لۆگۆ و ڕوونکردنەوە.
- **سەلامەتی**: کۆدی ڕەنگی کڵاو، جۆر و پۆلی کڵاو، ستانداردەکان و 21 جۆر PPE.
- **توێژینەوەی بەکالۆریۆس** (PDF) و **کەناڵی تێلێگرام** بۆ فێربوونی زمانی ئەڵمانی: [t.me/Yad_abdalla](https://t.me/Yad_abdalla)

## وێنەکان

- وێنەی بەشەکان لە **Pexels** (بەخۆڕایی) ڕاستەوخۆ بانگ دەکرێن.
- وێنەی ئەندازیاران و پڕۆژەکان لە API ی **ویکیپیدیا / ویکیمیدیا کۆمنز** وەردەگیرێن و لە وێبگەڕدا هەڵدەگیرێن.
- لۆگۆی نەرمەکاڵاکان لە **Simple Icons** دێن.
- ئەگەر وێنەیەک نەگەیشت، پیتی یەکەمی ناو یان ئایکۆنی بەشەکە پیشان دەدرێت.

## چۆن بیکەیتەوە

ماڵپەڕەکە تەنها HTML/CSS/JavaScript ـە و پێویستی بە build نییە:

```bash
python3 -m http.server 8000
# پاشان بکەرەوە: http://localhost:8000
```

- **Cloudflare Pages**: Workers & Pages → Create → Pages → Upload assets، و فۆڵدەرەکە (یان ZIP ەکە) ڕابکێشە.
  - گرنگ: `index.html` دەبێت ڕاستەوخۆ لە سەرەوەی ZIP ـەکەدا بێت، نەک لە ناو فۆڵدەرێکدا؛ ئەگەرنا Cloudflare هەڵەی 404 پیشان دەدات. بۆ دروستکردنی: `git archive --format=zip -o site.zip HEAD -- index.html assets`
- **GitHub Pages**: Settings → Pages → Deploy from a branch، و فۆڵدەری `/ (root)` هەڵبژێرە.
- زمان بە `?lang=ku|ar|en|de` لە بەستەرەکەدا دیاری دەکرێت.
- دوای گۆڕینی هەر فایلێکی `assets`، ژمارەی `v=5` لە `index.html` و `V` لە `app.js` زیاد بکە، بۆ ئەوەی وێبگەڕ وەشانی نوێ بهێنێت.

## پێکهاتەی فایلەکان

```
index.html                 پەڕەی سەرەکی
assets/css/style.css       دیزاین و جوڵەی نووسینەکان
assets/fonts/*.woff2       فۆنتی Zain (400/700/900 × کوردی/عەرەبی + لاتینی)
assets/js/app.js           ڕووکار، ڕێڕەو (#/dept/<id> و #/tools …)، زمانەکان و جوڵەی نووسین
assets/js/pages/*.js       پەڕەکان: tools، standards، projects (مۆدێلی 3D)، universities، styles
assets/js/bg.js            باکگراوندی جووڵاوی هەر بەش (canvas)
assets/js/icons.js         ئایکۆنەکان
assets/data/core.js        داتای هاوبەش: ڕەنگ، لقەکان، نەرمەکاڵا، وێنە
assets/data/<lang>/ui.js   دەقی ڕووکار بۆ هەر زمانێک (ku, ar, en, de)
assets/data/<lang>/<id>.js دەقی هەر بەشێک و ئەندازیارانی
assets/data/<lang>/sw.js   ڕوونکردنەوەی نەرمەکاڵاکان
assets/data/<lang>/home.js ڕێبەر، ئەندازیارانی کورد، توێژینەوە و تێلێگرام
assets/data/<lang>/<page>.js دەقی هەر پەڕەیەک (tools، standards، projects، universities، styles)
assets/img/                وێنەکانی ئەندازیارانی کورد و دوو ئەندازیار، و بەرگی توێژینەوە
assets/docs/               PDF ی توێژینەوەکە
```

> تێبینی: ڕەنگی کڵاوی بەشەکان لەم ماڵپەڕەدا بۆ ناساندن و جیاکردنەوەیە؛ لە سایتی ڕاستەقینەدا ڕێسای کۆمپانیا و وڵات پەیڕەو دەکرێت.
