# وێبسایتی بۆردی وەرزشیی یەکێتیی نیشتمانیی کوردستان

وێبسایتێکی داینامیک بۆ بڵاوکردنەوەی هەواڵ، وێنە و چالاکییەکانی بۆردی وەرزش.

- **خەڵکی ئاسایی** سایتەکە دەبینن: هەواڵەکان، وێنەکان، گەڕان، بەشەکان، دەربارە و پەیوەندی.
- **تەنها تۆ** بە **کۆدێکی نهێنی** دەچیتە ناو **کۆنترۆڵ پانێڵ** (`/admin`) و ڕۆژانە وێنە و نووسین دادەنێیت.

دیزاینەکە لەسەر کیتی جوڵە و فۆنت و ڕەنگی بۆردی وەرزش دروستکراوە — بڕوانە [docs/motion-kit.md](docs/motion-kit.md).

---

## ١. بڵاوکردنەوە لەسەر Cloudflare (پێشنیارکراو — بەخۆڕایی)

سایتەکە لەسەر **Cloudflare Workers** کار دەکات، و بابەت و وێنەکان لە **Cloudflare D1** (داتابەیس) پاشەکەوت دەکرێن.
هیچ کارتی بانکی پێویست نییە.

### هەنگاوەکان (تەنها لە وێبسایتی Cloudflare ـەوە)

1. بچۆ [dash.cloudflare.com](https://dash.cloudflare.com) و هەژمارێک دروست بکە (ئەگەر نییە).
2. **داتابەیس دروست بکە:** Storage & Databases → **D1 SQL Database** → **Create** → ناوی بنێ `puk-sports` → Create.
   پاشان **Database ID** ـەکە کۆپی بکە (شتێکی وەک `a1b2c3d4-...`).
3. لە GitHub فایلی `wrangler.toml` بکەرەوە و ئەم دێڕە بگۆڕە:
   ```toml
   database_id = "00000000-0000-0000-0000-000000000000"
   ```
   بۆ ئەو ID ـیەی کۆپیت کرد، و پاشەکەوتی بکە (Commit).
4. **سایتەکە دروست بکە:** Workers & Pages → **Create** → **Import a repository** → GitHub ببەستەوە و ڕیپۆی
   `puksportsboard` هەڵبژێرە. ڕێکخستنەکان وەک خۆیان بهێڵەرەوە (Deploy command: `npx wrangler deploy`) → **Deploy**.
5. **کۆدی نهێنی دابنێ:** لە Worker ـەکەدا → **Settings** → **Variables and Secrets** → **Add** →
   جۆر: **Secret**، ناو: `ADMIN_CODE`، بەها: کۆدەکەی خۆت (بۆ نموونە `Puk-Sport-2026!`) → **Deploy**.
6. تەواو! سایتەکە لەسەر `https://puk-sports-board.<ناوی-هەژمارەکەت>.workers.dev` کار دەکات.
   کۆنترۆڵ پانێڵ: `.../admin`

**دۆمەینی تایبەت** (وەک `puksport.krd`): Worker → Settings → **Domains & Routes** → Add → Custom domain.
پاشان گۆڕاوی `SITE_URL` (جۆری Text) دابنێ بۆ `https://puksport.krd` تا وێنەکان لە فەیسبووک و واتساپ دروست دەربکەون.

لەمەودوا هەر گۆڕانکارییەک لە GitHub بکرێت، Cloudflare خۆکار سایتەکە نوێ دەکاتەوە. بابەت و وێنەکان لە D1 ـدان و
بە نوێکردنەوە ناسڕێنەوە.

### سنووری بەخۆڕایی Cloudflare

| | سنوور | بۆ ئێمە واتای چییە |
|---|---|---|
| Workers | ١٠٠,٠٠٠ سەردان لە ڕۆژێکدا | زۆر زیاترە لە پێویست |
| D1 | ٥ گیگابایت | نزیکەی ١٥,٠٠٠ وێنە (هەر وێنەیەک ~٣٠٠KB) |
| D1 | ٥ ملیۆن خوێندنەوە لە ڕۆژێکدا | وێنەکان لە کاشی Cloudflare هەڵدەگیرێن، بۆیە کەم دەخوێندرێنەوە |

### بە فەرمانی تێرمیناڵ (بۆ کەسانی تەکنیکی)

```bash
npx wrangler login
npx wrangler d1 create puk-sports        # ID ـەکە لە wrangler.toml دابنێ
npx wrangler secret put ADMIN_CODE
npx wrangler deploy
```

تاقیکردنەوە لەسەر کۆمپیوتەر: فایلێکی `.dev.vars` دروست بکە بە `ADMIN_CODE="test"` و پاشان `npx wrangler dev`.

## ٢. کۆنترۆڵ پانێڵ

| بەش | چی دەکات |
|---|---|
| **＋ بابەتی نوێ** | ناونیشان، بەش، بەروار، چەند وێنەیەک (ڕاکێشان یان هەڵبژاردن)، نووسین. وێنەکان خۆکار بچووک دەکرێنەوە و دەنێردرێن. |
| **بابەتەکان** | لیستی هەموو بابەتەکان — بینین، دەستکاری، سڕینەوە. |
| **ڕێکخستنەکان** | لۆگۆ، وێنەی سەرەوە، ناوی سایت، دروشم، دەربارە، بەشەکان، تەلەفۆن، ئیمەیڵ، سۆشیاڵ میدیا، گۆڕینی کۆد. |

- **ڕەشنووس:** ئەگەر «بڵاوکراوە» لابدەیت، بابەتەکە پاشەکەوت دەبێت بەڵام خەڵک نایبینن.
- **بابەتی سەرەکی:** بە گەورەیی لە سەرەوەی لاپەڕەی سەرەکی دەردەکەوێت (ئەگەر هیچیان دیاری نەکرابێت، نوێترین بابەت).
- **نووسین:** دێڕی بەتاڵ = پەرەگرافی نوێ. `**وشە**` = تۆخ. بەستەرەکان خۆکار دەبنە لینک.
- دوای ٨ هەوڵی هەڵە، چوونەژوورەوە بۆ ١٥ خولەک دادەخرێت.
- کۆدی `ADMIN_CODE` هەمیشە کار دەکات؛ ئەو کۆدەی لە پانێڵەوە دادەنرێت کۆدێکی زیادەیە.
- لۆگۆ و بانەری بنەڕەت لە `public/img/logo.png` و `public/img/banner.jpg` ـدان.

## ٣. کارپێکردن بە Node.js (کۆمپیوتەر یان VPS)

هەمان سایت بەبێ Cloudflare ـیش کار دەکات. پێویستت بە [Node.js](https://nodejs.org) ـە (١٨+)، هیچ پاکێجێکی تر نا:

```bash
ADMIN_CODE=کۆدەکەت node server.js
```

سایتەکە: http://localhost:3000 — کۆنترۆڵ پانێڵ: http://localhost:3000/admin

داتاکان لە بوخچەی `data/` ـدان (یان `DATA_DIR`) — بۆ باکئەپ تەنها ئەم بوخچەیە کۆپی بکە.
`Dockerfile` ـیش ئامادەیە (`-v puk-data:/data`).

## ٤. پێکهاتەی پڕۆژەکە

```
src/app.js           ناوەڕۆکی سەرەکی: لاپەڕەکان، API، چوونەژوورەوە (هاوبەش بۆ Cloudflare و Node)
src/worker.js        دەروازەی Cloudflare
src/store-d1.js      پاشەکەوتکردن لە Cloudflare D1
src/store-file.js    پاشەکەوتکردن لە فایل (Node)
server.js            سێرڤەری Node.js
wrangler.toml        ڕێکخستنی Cloudflare
public/admin.html    کۆنترۆڵ پانێڵ  (+ js/admin.js ، css/admin.css)
public/css/          tokens / components / motion (کیت) + site.css
public/js/           motion.js (کیت) + site.js
public/img/          لۆگۆ و بانەری بنەڕەت
public/_headers      سەرپەڕەکانی پاراستن بۆ Cloudflare
```

هەروەها `/feed.xml` (RSS)، `/sitemap.xml` و `robots.txt` (کۆنترۆڵ پانێڵ لە گووگڵ دەشارێتەوە) هەن.
