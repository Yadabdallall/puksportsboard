# ئەندازیارنامە — ئینسایکلۆپیدیای بەشە ئەندازیارییەکان

ئەم ماڵپەڕە ئینسایکلۆپیدیایەکی سادە و جێگیرە؛ تیشک دەخاتە سەر گرنگترین بەشەکانی ئەندازیاری، سروشتی کارکردنیان، نەرمەکاڵا سەرەکییەکان، و بوارەکانی کار لە هەریەکەیاندا. ئامانجمان هاوکاریکردنی تۆیە لە تێگەیشتن و هەڵبژاردنی دروستی بەشەکەت.

**4 زمان:** کوردی (سۆرانی) · العربية · English · Deutsch — هەموو ژمارەکان بە لاتینی (0-9) و تەنها فۆنتی **Zain** بەکاردێت (لە ناو ماڵپەڕەکە خۆی دانراوە، بۆ خێرایی).

دیزاینەکە سادە و minimal ـە: کڵاوەکان ناجووڵێن، نووسینەکان بە نەرمی دێڕ بە دێڕ و وشە بە وشە دەردەکەون (کیتی جوڵەی تێکست)، و باکگراوندە جووڵاوەکەی هەر بەشێک وەک خۆی ماوە.

## چی تێدایە؟

- **14 بەشی ئەندازیاری**: شارستانی، تەلارسازی، میکانیک، کارەبا، کۆمپیوتەر، نەرمەکاڵا، گەیاندن، کیمیا، نەوت، سەرچاوەکانی ئاو، پزیشکی، ئاسمانی و فڕین، پیشەسازی، ڕووپێوی و جیۆماتیکس — لەگەڵ کورتەی 10 بەشی تر.
- بۆ هەر بەشێک: بەشەکە چۆنە، سروشتی کارکردن، وانەکانی هەر قۆناغێک (لەگەڵ تێبینی کە وانەکان بەپێی زانکۆ و وڵات و شار دەگۆڕێن)، لقەکان، ماستەر و دکتۆرا، نەرمەکاڵا، بوارەکانی کار، سەلامەتی و «ئایا دەزانی؟».
- **ڕەنگ و باکگراوندی تایبەت بۆ هەر بەش**: کاتێک دەچیتە ناو بەشێک، کڵاوەکەی بە ئەنیمەیشن لەسەرت دادەنرێت و باکگراوندەکە دەگۆڕێت بۆ دیمەنێکی جووڵاوی تایبەت بەو بەشە (پرد و قولاب، نەخشەی خانوو، چەرخ و پیستۆن، شەپۆلی کارەبا، تەختەی ئەلیکترۆنی، مۆلیکول، بیری نەوت، شەپۆلی ئاو، ECG و DNA، خولگەی مووشەک، هێڵی بەرهەمهێنان، هێڵی کۆنتۆر …).
- **140 ئەندازیاری مەزن** (10 کەس بۆ هەر بەش) لەگەڵ ژیاننامە و 3 پڕۆژەی جیهانی بۆ هەر کەسێک.
- **110 نەرمەکاڵا** لەگەڵ لۆگۆ؛ کرتە بکە بۆ ڕوونکردنەوە، کێ بەکاری دەهێنێت و نموونەی کارە گەورەکان — لەگەڵ بەستەری ویکیپیدیا و وێنەکان لە گووگڵ.
- **سەلامەتی**: کۆدی ڕەنگی کڵاو، جۆر و پۆلی کڵاو، شێوەکانی کڵاو، ستانداردەکان و 21 جۆر کەرەستەی پاراستنی کەسی (PPE).
- تاقیکردنەوەیەکی 6 پرسیاری بۆ دۆزینەوەی گونجاوترین بەش.

## وێنەکان

- وێنەی بەشەکان لە **Pexels** (بەخۆڕایی) ڕاستەوخۆ بانگ دەکرێن.
- وێنەی ئەندازیاران و پڕۆژەکان لە API ی **ویکیپیدیا / ویکیمیدیا کۆمنز** وەردەگیرێن و لە وێبگەڕدا هەڵدەگیرێن.
- لۆگۆی نەرمەکاڵاکان لە **Simple Icons** دێن.
- ئەگەر وێنەیەک نەگەیشت، پیتی یەکەمی ناو یان ئایکۆنی بەشەکە پیشان دەدرێت.

## چۆن بیکەیتەوە

ماڵپەڕەکە تەنها HTML/CSS/JavaScript ـە و پێویستی بە build نییە:

```bash
python3 -m http.server 8000
# پاشان بکەرەوە: http://localhost:8000
```

- **Cloudflare Pages**: Workers & Pages → Create → Pages → Upload assets، و فۆڵدەرەکە (یان ZIP ەکە) ڕابکێشە.
- **GitHub Pages**: Settings → Pages → Deploy from a branch، و فۆڵدەری `/ (root)` هەڵبژێرە.
- زمان بە `?lang=ku|ar|en|de` لە بەستەرەکەدا دیاری دەکرێت.
- دوای گۆڕینی هەر فایلێکی `assets`، ژمارەی `v=4` لە `index.html` و `V` لە `app.js` زیاد بکە، بۆ ئەوەی وێبگەڕ وەشانی نوێ بهێنێت.

## پێکهاتەی فایلەکان

```
index.html                 پەڕەی سەرەکی
assets/css/style.css       دیزاین و جوڵەی نووسینەکان
assets/fonts/*.woff2       فۆنتی Zain (400/700/900 × کوردی/عەرەبی + لاتینی)
assets/js/app.js           ڕووکار، ڕێڕەو (#/dept/<id>)، زمانەکان و جوڵەی نووسین
assets/js/bg.js            باکگراوندی جووڵاوی هەر بەش (canvas)
assets/js/icons.js         ئایکۆنەکان
assets/data/core.js        داتای هاوبەش: ڕەنگ، لقەکان، نەرمەکاڵا، وێنە
assets/data/<lang>/ui.js   دەقی ڕووکار بۆ هەر زمانێک (ku, ar, en, de)
assets/data/<lang>/<id>.js دەقی هەر بەشێک و ئەندازیارانی
assets/data/<lang>/sw.js   ڕوونکردنەوەی نەرمەکاڵاکان
```

> تێبینی: ڕەنگی کڵاوی بەشەکان لەم ماڵپەڕەدا بۆ ناساندن و جیاکردنەوەیە؛ لە سایتی ڕاستەقینەدا ڕێسای کۆمپانیا و وڵات پەیڕەو دەکرێت.
